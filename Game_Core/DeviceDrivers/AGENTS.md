# DeviceDrivers — дисплейные драйверы (header-only)

Оба драйвера — header-шаблоны: `Display/Inc/st7789.hpp`, `st7735.hpp`.
Wiring целиком в non-type шаблонных параметрах — компилятор штампует
константы в тела транзакций, объект драйвера не несёт состояния (только
scratch: ST7735 320 Б / ST7789 416 Б). Инстанцируют и создают объект в
`Platforms/*/Core/Src/main.cpp`; стыковка с ядром — concept `Disp`
(`Display/Inc/disp.hpp`).

Разделение ролей: контракт использования (вход/выход, пример, ловушки
потребителя) — `README.md` рядом; здесь — правила изменения.

## Параметры wiring — семантика

- `HSPI` — хэндл SPI как pointer-NTP (`&hspi1`/`&hspi4`, адрес линкуется).
- Порты — **целые `GPIOx_BASE`**, не `GPIO_TypeDef*`: Clang-21 отвергает
  round-trip `reinterpret_cast` как constant expression; материализация
  указателя — внутри `port()`-функции драйвера.
- DC всегда заведён; CS/RST — 0, если линия не заведена
  (гварды `if (RST_ADDR)` / `if (CS_ADDR && !SINGLE)` вычисляются на
  компиляции, ветки не генерируются).
- `sizes`, `single_device`, биты MADCTL/инверсии — параметры; геометрия
  `w()/h()` — constexpr; init-таблица — `static constexpr` во flash.

## Контракт Disp — асимметричный по дизайну

- Blit-путь `LcdT::print(x, y, w, h, img)` — **статический** (состояния
  нет): сущности ядра зовут без объекта и указателя.
- Lifecycle `init()/select()/unselect()` — instance-методы: их дёргает
  единственный объект, на который `GameT` держит ссылку.
- `print_img` обязан быть **noinline** — иначе тело SetWindow+DMA
  реплицируется в каждый print/clear-сайт (+1–3 КБ flash, ADR-0004).

## Шина и CS-окно

- Драйвер не дёргает CS внутри транзакций: `select()/unselect()` публичные,
  кадр обрамляет сама Game (см. Game/AGENTS.md).
- `single_device` («CS есть, но шина собственная») — `init()` выбирает
  прямым GPIO-письмом, `select()/unselect()` далее no-op.
- Boot-clear — flash-стрипы `disp_clear_240x16`/`disp_clear_160x16`
  (assets.cpp); каждая платформа определяет только свой стрип.
- Данные идут DMA из flash напрямую — штатно на F4; кэш-обязанностей нет
  (прошивка неизменяема, DMA кэш не использует — ADR-0007).

## Не трогать

- init-таблицы: value-init явно — `{ CMD, 0, {} }` (коммит `380eecb`,
  `-Wextra` чист).
- `fonts.c` — резерв, не числится ни в одной цели: не компилировать и не
  включать; будущий текст-HUD — отдельный STATIC-таргет (ADR-0003).
- `print_img` — noinline-инвариант (см. выше).
