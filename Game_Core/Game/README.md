# Game — игровой слой

Контракт использования. Правила изменения — `AGENTS.md` рядом.

## Назначение

Сущности и кадр: `GameT<LcdT>` — полный игровой кадр над панелью
`LcdT` (спавн, симуляция, коллизии, отрисовка); `MapT<LcdT>` —
сетка местности (terrain), сворачиваемая из авторской карты под
геометрию панели.

За что НЕ отвечает: подключение (wiring) драйвера и шину (платформа),
темп кадра (платформа), ввод.

## Вход / Выход

- `GameT<LcdT> game(lcd)` — панель по ссылке; пулы и карта внутри,
  всё на стеке вызывающего.
- `game.init()` — boot-clear, раскладка карты, начальный спавн.
- `game.loop()` — один кадр: спавн → танковая фаза (без отрисовки) →
  `disp.select()` (открытие CS-окна) → снарядная фаза → перерисовка
  разрушенного кирпича → lull-проходы (вытолкновение уничтоженных
  сущностей) → проходы отрисовки → `bush_flush` → `disp.unselect()`.
- `GameT::fld_x_end/fld_y_end` — constexpr концы поля.
- `MapT<LcdT>` — constexpr-сетка: `rows/cols/row0/col0`, `at(r, c)`;
  панель = окно-кроп или вся карта. Легенда авторской карты:
  `.` пусто, `#` кирпич, `X` сталь, `~` вода, `*` куст.
- Ручки `cfg::` (`config.hpp`): `spawn_margin_px=30`,
  `spawn_slots=7`, `units_per_side=4`, `map_cell_px=8`.

## Пример применения

Реальные call-sites: `Platforms/STM32F401/Core/Src/main.cpp`,
`Platforms/STM32H743/Core/Src/main.cpp`, тестовый двойник (fake) —
`tmp/host_test/main.cpp`. Упрощённо:

```cpp
using Lcd = ST7789<&hspi1, /* wiring — см. main.cpp платформы */>;
Lcd lcd;
GameT<Lcd> game(lcd);
game.init();
for (;;) { game.loop(); HAL_Delay(15); }  // 15 мс — темп кадра
```

## Предупреждения при использовании

- Один `loop()` = один кадр; blit'ы допустимы только внутри — CS-окно
  кадра открывает/закрывает сам `loop()`.
- Уничтоженные сущности должны быть вытолкнуты из пулов до конца
  кадра (lull-проходы): иначе `spawn()` примет мёртвый танк за живой
  и забронирует его слот спавна повторно.
- Деструкторов Tank/Shell не существует — слоты переиспользуются
  переконфигурацией (`respawn`/`get_out`).
- Случайность — `rand()` (три вызова на танк): воспроизводимость
  задаёт фиксированный сид вызывающего кода.
- Спавн-геометрия охраняется static_assert'ами: правка карты,
  перекрывшая лестницу спавна, обнаружится на компиляции.
