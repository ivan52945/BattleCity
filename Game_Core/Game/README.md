# Game — игровой слой

Контракт использования. Правила изменения — `AGENTS.md` рядом.

## Назначение

Сущности и кадр: `GameT<LcdT>` — полный игровой кадр над панелью
`LcdT` (спавн, симуляция, коллизии, отрисовка); `MapT<LcdT>` —
сетка местности (terrain), сворачиваемая из авторской карты под
геометрию панели.

За что НЕ отвечает: подключение (wiring) драйвера и шину (платформа),
темп кадра (платформа), ввод.

## Вход / Выход

- `GameT<LcdT> game(lcd)` — панель по ссылке; пулы и карта внутри,
  всё на стеке вызывающего.
- `game.init()` — boot-clear, раскладка карты, начальный спавн.
- `game.loop()` — один кадр: спавн → танковая фаза (без отрисовки) →
  `disp.select()` (открытие CS-окна) → снарядная фаза → перерисовка
  разрушенного кирпича → lull-проходы (вытолкновение уничтоженных
  сущностей) → проходы отрисовки → `bush_flush` → `disp.unselect()`.
- `GameT::fld_x_end/fld_y_end` — constexpr концы поля.
- `MapT<LcdT>` — сетка местности над панелью; контракт — раздел
  «Карта» ниже.
- Ручки `cfg::` (`config.hpp`): `spawn_margin_px=30`,
  `spawn_slots=7`, `units_per_side=4`, `map_cell_px=8`.

## Карта: `MapT<LcdT>`

Сетка местности над панелью; сетка и кроп сворачиваются на компиляции.

- Координаты клеток — **панельные** (окно): `rows/cols` = панель/клетка,
  `row0/col0` — центрирующий кроп авторской карты (точное совпадение
  размеров = вся карта, `row0 == col0 == 0`). `at(r, c)` — constexpr
  lookup; выход за края авторской сетки заворачивается (wrap).
- Легенда авторской карты: `.` пусто, `#` кирпич, `X` сталь, `~` вода,
  `*` куст.
- `spawn_free(x, y)` — весь корпус танка в точке (пиксели, центр,
  полуразмеры корпуса) сидит на проходимых клетках: пустота и куст
  проходимы, кирпич/сталь/вода — нет. Края поля не клампятся — их
  держит лестница спавна (compile-time охрана).
- `blocks(x, y, w, h)` — перекрывает ли местность прямоугольник
  (`x/y` — левый-верхний угол, `w/h` — размеры; выходящие края
  клампятся в поле): сталь и вода блокируют, целый кирпич блокирует,
  снесённый кирпич, пустота и куст — нет.
- `hit(x, y, w, h)` — попадание снаряда в прямоугольник: сталь убивает
  снаряд и не разрушается; целый кирпич сносится (бит `destroyed` +
  запрос перерисовки) и убивает снаряд; снесённый кирпич, вода и
  пустота пропускают. Возврат — «снаряд погиб».
- `flush_destroyed()` — однокадровая перерисовка снесённого: каждая
  dirty-клетка закрашивается очисткой, бит гасится (повторный flush
  — ноль blit'ов).
- `tile_touch(x, y, w, h)` / `tile_flush()` — тайловая маска кадра:
  клетки под прямоугольником бронируются (сталь, вода, куст и целый
  кирпич; снесённый кирпич и пустота — нет; дедупликация; переполнение
  книги в 32 клетки отбрасывается до следующего кадра), `tile_flush()`
  перекрашивает забронированные — «поездка под кустом» и ремонт тайлов,
  стёртых снарядами.
- `draw()` — стартовая покраска местности панели (непустые клетки,
  пустота — фон; init, внутри drawing-цикла). `brick_down(r, c)` —
  запрос бита разрушения (панельные координаты).

## Танк: `Tank<LcdT>`

Корпус 13×13, `speed` = 1 px/кадр; кадры — flash-наборы по стороне
(`side == 0` союзные, иначе вражеские); `life = 2`.

- `move(...)` — шаг на `speed` по `dir`. Край поля зажимает (позиция =
  граница, `action = BLOCK`); шаг на блокирующую клетку местности
  откатывается целиком (net zero — «призраков» и полос нет);
  `stuck_cnt` копит блоки.
- `back(stuck, map)` — отталкивание: шаг против `dir`; толчок не
  замуровывает корпус в стену (стена съедает толчок — отталкиваемый
  остаётся на месте). Без print.
- `rotate(new_dir)` — `dir = new_dir % 4` (вызывающий даёт
  `new_dir ≥ 0`); кадровый буфер перенаправляется; `action = ROTATE`.
- `update(...)` — тик ИИ: насос направления (после 35 честных кадров
  или `stuck_cnt > 3` — ролл ~36%: поворот на случайную четверть;
  промах делит кулдаун пополам) → `move` → огневой ролл (после
  60-кадрового кулдауна ~46%: `shot_st = true`; промах делит кулдаун).
  Вероятности — за сидом `rand()` вызывающего.
- `isShot(...)` — съедает `shot_st` (один опрос = один выстрел);
  прицеливает снаряд на край корпуса по `dir`; у края поля выстрел
  отменяется (флаг уже съеден). Истина = «стреляли».
- `shot(shell)` — выдаёт снаряд из ствола (по прицелу последнего
  `isShot`).
- `respawn(x, y, side)` — `life = 2`, позиция, кулдауны и `stuck_cnt` —
  в ноль; `dir` по стороне (0 → 1, 1 → 3); кадры стороны.
- `kill()` — при `life > 0` ложь; иначе стирание спрайта (`clear`) и
  истина.

## Пример применения

Реальные call-sites: `Platforms/STM32F401/Core/Src/main.cpp`,
`Platforms/STM32H743/Core/Src/main.cpp`, тестовый двойник (fake) —
`tmp/host_test/main.cpp`. Упрощённо:

```cpp
using Lcd = ST7789<&hspi1, /* wiring — см. main.cpp платформы */>;
Lcd lcd;
GameT<Lcd> game(lcd);
game.init();
for (;;) { game.loop(); HAL_Delay(15); }  // 15 мс — темп кадра
```

## Предупреждения при использовании

- Один `loop()` = один кадр; blit'ы допустимы только внутри — CS-окно
  кадра открывает/закрывает сам `loop()`.
- Уничтоженные сущности должны быть вытолкнуты из пулов до конца
  кадра (lull-проходы): иначе `spawn()` примет мёртвый танк за живой
  и забронирует его слот спавна повторно.
- Деструкторов Tank/Shell не существует — слоты переиспользуются
  переконфигурацией (`respawn`/`get_out`).
- Случайность — `rand()` (три вызова на танк): воспроизводимость
  задаёт фиксированный сид вызывающего кода.
- Спавн-геометрия охраняется static_assert'ами: правка карты,
  перекрывшая лестницу спавна, обнаружится на компиляции.
