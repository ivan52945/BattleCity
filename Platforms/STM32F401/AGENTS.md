# Platforms/STM32F401 — CubeMX-проект (ST7789 240×240)

Использование, сборка и настройки платы — `README.md` рядом; здесь —
правила изменения. Тулчейн `cmake/gcc-arm-none-eabi.cmake` (`-Os -g0`);
`starm-clang.cmake` рядом — паритет флагов проверен (пункт B).
Базлайны — `docs/metrics.md`.

## Память

- Стек-резерв `0x1800` (6 144 Б) — честен против фактического расхода
  (коммит `2e4f7fb`, пункт Q); heap `0x200`.
- `GameT` = 5 608 Б на стеке; резерв покрывает с запасом ~536 Б
  (metrics.md).
- Базлайн: FLASH 32 372 / RAM 7 392 (после terrain-сессии).

## Дисциплина CubeMX

- Проект генерируется из `Tanks_F401.ioc`: массовые правки — только по
  явному согласию пользователя.
- `main.cpp` рукописный: реген пересоздаёт `main.c`-скелет — его сносить,
  `main.cpp` реген не трогает.
- `.ld` править только в границах MEMORY/MX-маркеров — пользовательские
  строки переживают реген.
