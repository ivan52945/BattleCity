# ADR-0008 — Terrain-карта: constexpr-сетка, спавн-дисциплина, bush-masking

Статус: принято (в дереве, не закоммичено на момент ADR). Дата: 2026-11-11.

## Контекст

Поле было плоским: никакого terrain, силуэт уровня примитивен. Хост-тест
протух после смены сигнатур. Ограничение: RAM не двигается (стек), такт не
драгоценен (wire-bound), compile-time ресурсы свободны.

## Решение

- **Авторская карта → constexpr-сетка:** `map_layout::rows_txt` (30×30,
  легенда `.` пусто / `#` кирпич / `X` сталь / `~` вода / `*` куст) парсится
  в flash-сетку байт на этапе компиляции (`inline constexpr grid`),
  runtime-парсинга нет. Дисциплина свёрнута в static_assert'ы: длина каждой
  строки == cols, символ вне легенды — ошибка сборки.
- **`MapT<LcdT>`:** панельная сетка клеток `cfg::map_cell_px = 8` из
  `LcdT::w()/h()` (F401 240×240 → 30×30, H743 160×80 → 20×10); окно в
  авторскую карту — центр-кроп (`row0/col0`), панель больше карты — wrap
  (double-mod). Спрайты 8×8 × 4 вида (aligned(32), 512 Б flash).
- **Спавн-дисциплина compile-time:** `MapT::spawn_free(x, y)` — корпус
  танка на точке без solid; `GameT::ladder_free()` + static_assert по всей
  лестнице инстанциации: правка карты, перекрывшая спавн, валит сборку той
  платформы. Keep-out'ы лестницы F401 (колонки/ряды 3–4 и 25–27) и кропа
  H743 (src-ряды 13–17 × колонки 8–9 / 20–22) выдержаны.
- **Коллизии танк-карта:** шаг на solid → откат шага (net-zero — контракт
  BLOCK держится, ghost-полос нет); `stuck_cnt` кормится как на clamp'е;
  перпендикулярный снап к сетке 8 px при упоре с guard'ом «снап не зарывает
  корпус в соседнюю стену» (двери 2 клетки проходимы для корпуса 13 px).
  `Tank::back()` принял map — толчок в стену откатывается (задавленный в
  кирпич танк выходит).
- **Снаряд-карта:** корпус ориентированный (w/h вертикальные); сталь убивает
  снаряд, вода пропускает, кирпич сносится и убивает; снос — два битсета
  по панельной клетке (`destroyed` — персистентный для коллизий, `dirty` —
  одноразовый repaint), repaint — `map.flush_destroyed()` после снарядной
  фазы, внутри CS-окна.
- **Bush pass:** boot-покраска в `init()` (свой select/unselect-цикл);
  покадрово `bush_book(entity)` — консервативный бокс «спрайт + speed»
  (print-полосы и clear-прямоугольники кадра не покидают бокс), dedup ≤16,
  overflow сбрасывается (клетка перебронируется в следующем кадре); booked:
  труп танка, дохлый снаряд, оба print-цикла. `map.bush_flush()` — последний
  blit кадра перед unselect: «проехал под кустом» прячет танки и снаряды.
- **Сигнатуры/проводка:** `Tank::update/move/back`, `Shell::update/move`
  приняли `MapT<LcdT>&`; `resolve_collision` (танк-танк) — static с map;
  `GameT` + поле `map`. Host-тест дополнен второй fake-панелью 160×80
  (кроп, лестница, cell-пробы).

## Последствия

- Stack: `GameT` 5 344 → 5 608 (+264 = MapT-битсеты 113×2 + bush-книга 36 +
  паддинг; указателей нет, расклад ABI-независимый); резерв F401 6 144
  честен (запас ~536 Б).
- FLASH: F401 29 600 → 32 372 (+2 772), H743 31 480 → 34 096 (+2 616);
  RAM const (7 392 / 1 904). `main.cpp` платформ не тронут.
- Живой прогон на обеих платах (кирпич/сталь/вода/кусты, снап у дверей,
  маскировка под кустом) — за пользователем.
