# ADR-0003 — Консолидация драйверов в единственный модуль Display

Статус: принято. Дата: ≈2026-11-03.

## Контекст

После NTP-wiring (ADR-0002) оба драйвера — header-шаблоны; папочная
структура `ST7735/` и `ST7789/` себя изжила.

## Решение

- Папки `ST7735/`, `ST7789/` упразднены; всё — в `DeviceDrivers/Display`:
  заголовки драйверов и `fonts.h`/`color.h` — в `Inc/`, `fonts.c` — в
  `Src/` **не компилируется** (резерв).
- Единственная цель `display` — INTERFACE: include-путь `Inc` + INTERFACE
  ссылка на `stm32cubemx` (заголовки драйверов включают `main.h`).
- Платформенные линковки урезаны до `game_core display stm32cubemx`.

## Последствия

- Кодогенерация не тронута: H743 26 940 / 28 / 1 896 (RAM 1 920), F401
  18 116 / 24 / 1 816 — байт-в-байт с пре-консолидационной сборкой.
- `fonts.o` больше не существует — шрифты не могут попасть в прошивку
  «случайным взглядом» (пункт C); будущий текст-HUD — отдельный
  STATIC-таргет рядом с INTERFACE-целью (заготовка — комментарий в
  `Display/CMakeLists.txt`).
